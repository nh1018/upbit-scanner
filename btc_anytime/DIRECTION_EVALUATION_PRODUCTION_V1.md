## Append-only operation

Natural key is unchanged: decision/evaluator/evaluation parameter/anchor contract/source contract/horizon. Existing finalized labels are hash/envelope/key validated and skipped without recomputing metrics. New eligible keys use the unchanged evaluator. PENDING never creates files. SOURCE_MISSING/PARTIAL-gap/INVALID/SOURCE_CONFLICT are separate immutable events; repeating identical payload produces no new event. Return-MATURED with full observable path becomes a finalized label; diagnostic excursion stays PARTIAL with its two approved warnings. Neutral directional return, MFE/MAE and directional hits remain null.

Label content hash is artifact_id; first actual recorded_at and envelope_hash preserve recording audit separately from source clocks. Raw hashes, received/observed clocks and precise source references are kept in payload. Full Direction snapshot is not duplicated. No periodic aggregate report is stored: existing aggregate() can produce deterministic reports from label payloads, with input payload hashes/report_id. Reports can be requested separately with a chosen input cutoff.

Workflow concurrency queues evaluation jobs independently; existing per-label exclusive writer prevents overlapping local writes. Only newly added JSON under output_direction/btc_anytime/v1/evaluation may be committed. Standard push retries fetch/rebase disjoint changes; same-file conflict fails closed, never force pushes. The publication step also preserves valid diagnostic/failure events after record failure; run still reports failure. No-op/PENDING-only run creates no commit. Exact input Git revision and real cutoff are included in run summary. Current failures cannot block ingestion or Direction workflows.
